# AI 辅助论坛 · Phase0 社区基础骨架 - 技术规范文档（PRD）

## Overview
- **Summary**：Phase0（阶段1）是 AI 辅助论坛的 MVP 起步阶段，目标是完成「用户进入 → 浏览 → 发帖 → 评论 → 个人主页」的基础社区闭环，不含 AI 能力接入。核心交付包括：登录注册承接页、未登录 5 分钟浏览计时与强制认证、首页推荐内容流、版块列表与分类浏览、帖子详情与楼中楼评论、发帖编辑器、个人主页、基础用户后台查看。所有数据通过前端 Mock 驱动，为后续接入后端 API 预留接口层。
- **Purpose**：搭建完整的社区骨架与用户交互闭环，验证信息架构、导航流和核心页面间跳转的正确性，确保 Phase2-5 的 AI 功能可在稳定的前端框架上增量开发。
- **Target Users**：大众兴趣浏览用户（未登录短时浏览）、提问求助用户、内容创作者、深度讨论用户、社区运营人员（基础查看权限）。

## Goals
- G1：完成未登录 5 分钟浏览的计时与认证流程（4:30 轻提示 → 5:00 强制阻断）
- G2：搭建前台 8 个核心页面的可交互骨架与页面间跳转
- G3：实现帖子列表、详情、评论（含楼中楼）、发帖编辑器的完整数据流
- G4：实现个人主页的资料卡、发帖/收藏/关注切换、影响力指标展示
- G5：搭建后台总览与基础用户查看页面骨架
- G6：完成路由守卫与权限控制（未登录拦截发帖/互动等能力）

## Non-Goals（Out of Scope）
- 不接入真实后端 API，不搭建 FastAPI 服务（后端为 Phase2+ 内容）
- 不实现 AI 能力（发帖助手、答疑、讨论总结、推荐、治理等全部留待 Phase2-4）
- 不实现真实注册/登录逻辑，仅提供 Mock 登录入口与登录态持久化
- 不实现内容搜索、通知中心、举报等前台复杂交互（留待 Phase3-5）
- 不实现后台审核、版块配置、举报处理等运营深度功能（留待 Phase4）
- 不实现真实关注/收藏/点赞的写入操作，仅 Mock 展示与前端状态切换

## Background & Context
- 当前项目已使用 React 18 + Vite 5 + React Router DOM v6 + Tailwind CSS 3 搭建，作品集项目与 AI 论坛共存于同一前端仓库，路由前缀为 `/forum/*`。
- 代码结构已对齐 AGENTS.md 约定：`pages/ai-forum/` 页面层、`components/ai-forum/` 组件层、`utils/ai-forum/` 工具层、`styles/ai-forum.css` 样式文件。
- `AuthProvider.jsx` 已实现未登录 5 分钟计时骨架（guestElapsed、guestStatus、authModal、requireAuth），需要在各页面正确接入。
- `mockData.js` 已提供覆盖全部实体的 Mock 数据（User、Post、Comment、Board、Topic、Notification 等），结构与 PRD §3 数据模型一致。
- Phase0 交付须严格遵循 AGENTS.md 中 React 编码规范、Tailwind 主题色复用、响应式断点与 Git 提交规范。

## Functional Requirements

### 核心流程类
- **FR-1**：未登录用户进入首页自动创建匿名浏览会话，启动 5 分钟计时；4 分 30 秒显示轻提示横幅，5 分钟整弹出强制认证遮罩（不允许关闭）。
- **FR-2**：未登录用户点击发帖、评论、点赞、收藏、关注、查看通知、进入个人主页编辑等操作时，即时弹出认证入口弹窗（对应 reason 文案）。
- **FR-3**：用户完成 Mock 登录后，匿名浏览计时归零、会话与账号绑定、认证弹窗关闭、返回原操作上下文。
- **FR-4**：登录态通过 localStorage 持久化（含隐私模式 try/catch 兜底），刷新页面不丢失。

### 首页与内容发现
- **FR-5**：首页展示推荐内容流（左栏 8 列），支持「最新 / 热门 / 关注」三种排序切换，关注流仅登录后可见。
- **FR-6**：首页右栏（4 列）包含 AI 推荐占位卡、热门话题标签墙、版块快捷入口列表，可点击跳转至搜索页或版块列表页。
- **FR-7**：首页每条帖子卡片展示标题、摘要（2 行截断）、作者头像+昵称、版块、最多 2 个标签、点赞数、评论数、相对时间。

### 版块列表页
- **FR-8**：版块列表页顶部展示所有版块导航卡片（含名称、描述、今日新帖、帖子数、关注数），可按治理模式视觉区分。
- **FR-9**：版块列表页支持按版块筛选帖子列表，支持最新/热门/优质排序，支持标签筛选。

### 帖子详情页
- **FR-10**：帖子详情页展示标题、正文 HTML、作者信息卡、所属版块、AI 摘要占位、标签。
- **FR-11**：评论区支持楼中楼回复（顶层评论 + 最多 2 层嵌套回复展示），每条评论展示作者、内容、点赞、回复按钮、相对时间。
- **FR-12**：帖子详情页提供互动工具栏（点赞、收藏、举报入口、分享），未登录点击时触发 FR-2 认证拦截。
- **FR-13**：帖子详情页侧栏展示「相关推荐」帖子列表，可跳转。

### 发帖编辑页
- **FR-14**：进入发帖编辑页前校验登录态，未登录直接跳转登录页并携带来源参数。
- **FR-15**：发帖编辑器支持标题输入、正文编辑（纯文本 + 换行段落即可，富文本留待 Phase2）、版块选择下拉、标签选择/输入（Mock 标签库）。
- **FR-16**：发帖编辑器右侧为 AI 助手面板占位区（Phase0 仅展示静态占位，不接入调用）。
- **FR-17**：发布成功后跳转至新帖详情页（使用 Mock 新帖 ID）。

### 个人主页
- **FR-18**：个人主页顶部展示用户资料卡：头像、昵称、Handle、职业、城市、加入时间、简介、关注/粉丝/帖子/收藏数量、影响力评分、关注/取消关注按钮（未登录触发认证）。
- **FR-19**：个人主页下方 Tab 切换区：发帖列表 / 收藏列表 / 关注列表 / 粉丝列表，各 Tab 使用 Mock 数据渲染。

### 登录注册页
- **FR-20**：登录注册页支持登录与注册 Tab 切换（两种表单均为 Mock 提交，不接后端）。
- **FR-21**：登录页承接浏览超时、发帖拦截、互动拦截三种来源，分别展示对应提示文案。
- **FR-22**：登录成功后根据来源参数返回原页面（如发帖拦截 → 跳转编辑器；浏览超时 → 返回当时帖子；默认 → 首页）。

### 后台总览（基础骨架）
- **FR-23**：后台总览展示核心指标卡（DAU、新帖数、待审、AI 调用数）、周趋势图占位、治理概览，均为 Mock 数据。
- **FR-24**：后台用户管理页面展示用户列表（含状态、角色筛选），点击可查看 Mock 用户详情。
- **FR-25**：后台四个其他管理页面（审核、版块、举报、运营配置）以页面骨架 + 占位形式存在，暂不做功能逻辑。

### 全局通用组件与布局
- **FR-26**：前台 ForumLayout 包含顶部导航栏（Logo、搜索框占位、发帖按钮、通知铃铛占位、头像下拉菜单）、内容主体区、底部版权信息。
- **FR-27**：顶部导航栏展示未登录剩余浏览时间或已登录用户入口，点击未登录时间区可查看进度。
- **FR-28**：认证弹窗 AuthModal 支持全局挂载，根据 reason 展示差异化文案，支持关闭（强制认证状态下不可关闭）。
- **FR-29**：所有页面响应式适配桌面（>1024px）、平板（768-1024px）、手机（<600px）三档断点。

## Non-Functional Requirements
- **NFR-1**：前端首屏冷加载 < 2s（本地 dev 环境），`npm run build` 构建成功且无致命警告。
- **NFR-2**：未登录计时精度误差 ≤ ±1s/分钟；5 分钟阈值到达必须在 1 秒内触发强制遮罩。
- **NFR-3**：所有页面跳转使用 `<Link>`，无整页刷新（外部链接除外）。
- **NFR-4**：localStorage 读写均包裹 try/catch，隐私模式下不抛异常。
- **NFR-5**：列表渲染 key 稳定使用实体 id，禁止使用 index。
- **NFR-6**：useEffect 均提供清理函数（定时器、事件监听），无内存泄漏。
- **NFR-7**：Tailwind 主题色严格复用 tailwind.config.js 已定义项，禁止硬编码 hex。
- **NFR-8**：代码文件均不超过 500 行，超过则拆分子组件或自定义 Hook。
- **NFR-9**：关键逻辑（计时阈值判断、路由守卫拦截、持久化兜底）添加中文注释说明「为什么」。

## Constraints
- **Technical**：
  - 前端框架锁定 React 18（函数组件 + Hooks）、Vite 5、React Router DOM v6、Tailwind CSS 3、JavaScript JSX（不引入 TypeScript）。
  - 不新增 npm 依赖，仅使用当前 package.json 中已有的 `lucide-react`、`react-router-dom` 等。
  - 数据层完全使用前端 Mock，新增数据写入仅更新前端状态（不调用后端接口）。
  - 样式方案：Tailwind 工具类为主，复杂选择器与动画写入 `src/styles/ai-forum.css`。
- **Business**：
  - Phase0 不做任何真实用户账号系统、不做持久化写入后端、不做部署上线。
  - Phase0 完成后必须可直接在 dev 服务器完整演示所有 FR 流程。
- **Dependencies**：
  - 依赖 `AuthProvider.jsx` 的认证上下文作为全局状态源。
  - 依赖 `mockData.js` 提供实体数据，依赖 `aiForumUtils.js` 的格式化函数（formatRelativeTime、formatNumber 等）。

## Assumptions
- A1：用户默认使用支持 IntersectionObserver、CSS Grid 等现代特性的浏览器（Chrome / Edge / Safari / Firefox 最新两个主版本）。
- A2：Phase0 阶段所有写操作（发帖、评论、点赞、收藏、关注）仅更新 React 状态，刷新页面后还原为 Mock 原始数据（可接受）。
- A3：Mock 登录用户使用 `mockData.js` 中的 `currentUser`，无需区分多个测试账号。
- A4：后台页面访问不做真实权限校验，登录后即可进入（真实权限控制留待 Phase4）。
- A5：首页「关注流」当前使用 Mock 截断数据展示（`list.slice(0, 3)`），后续接入真实关注关系后再替换。
- A6：未登录浏览计时在刷新页面时重置（符合 PRD 场景二的会话语义）。

## Acceptance Criteria

### AC-1：未登录 5 分钟浏览计时正常
- **Given**：用户未登录状态下访问 `/forum` 首页
- **When**：用户持续浏览页面不进行任何登录操作
- **Then**：
  1. 0 秒 ~ 4 分 29 秒：页面正常展示内容，无干扰提示
  2. 4 分 30 秒整：顶部显示轻提示横幅，文案说明「登录后获得完整体验」，横幅可手动关闭
  3. 5 分 00 秒整：弹出阻断式认证弹窗 + 页面内容遮罩，弹窗无关闭按钮，点击遮罩不关闭
  4. 在认证弹窗点击登录后，计时归零并返回正常浏览
- **Verification**：`programmatic`（检查 guestElapsed、guestStatus 状态迁移 + DOM 遮罩渲染）
- **Notes**：可通过临时修改 `GUEST_REMIND_SECONDS` / `GUEST_LIMIT_SECONDS` 为小值加速验证

### AC-2：未登录操作触发认证拦截
- **Given**：用户未登录状态下浏览首页或帖子详情
- **When**：用户点击「发帖」「点赞」「收藏」「关注」「查看通知」「进入个人主页编辑」任一按钮
- **Then**：
  1. 立即弹出认证弹窗，弹窗文案说明拦截原因（如「发帖需要登录」）
  2. 原操作未执行（如帖子点赞数不变）
  3. 弹窗可关闭（非强制状态下）
- **Verification**：`programmatic`（requireAuth 返回值 + 状态未变更）

### AC-3：Mock 登录与持久化
- **Given**：用户在登录页输入任意信息或直接点击登录按钮
- **When**：提交登录表单
- **Then**：
  1. 登录态切换为已登录，全局使用 `currentUser` 数据
  2. 刷新页面后登录态不丢失
  3. 清除 localStorage 后刷新页面回到未登录
  4. 退出登录后清除本地用户数据并重置浏览计时
- **Verification**：`programmatic`（localStorage 读写 + user 状态）

### AC-4：首页推荐内容流展示与排序
- **Given**：已登录或未登录用户访问首页
- **When**：切换「最新 / 热门 / 关注」排序
- **Then**：
  1. 「最新」按 createdAt 倒序排列
  2. 「热门」按 likes 降序排列
  3. 「关注」：未登录点击 → 触发 AC-2 认证拦截；已登录 → 展示 Mock 截断列表
  4. 每条帖子卡片展示字段完整（标题、摘要 2 行截断、作者、版块、标签 ≤2、点赞/评论数、时间）
- **Verification**：`programmatic`（排序结果断言 + DOM 字段完整性）

### AC-5：版块列表页筛选与导航
- **Given**：用户访问 `/forum/boards`
- **When**：点击版块导航卡或选择版块筛选器
- **Then**：
  1. 帖子列表只展示所选版块的帖子
  2. 切换最新/热门排序正确
  3. 标签筛选展示含该标签的帖子
- **Verification**：`programmatic`（列表过滤结果）

### AC-6：帖子详情页与评论楼中楼
- **Given**：用户访问 `/forum/post/:id`（如 p1）
- **When**：查看帖子内容与评论区
- **Then**：
  1. 帖子标题、正文、作者信息、版块、标签、AI 摘要展示正确
  2. 顶层评论与嵌套回复按层级缩进展示
  3. 互动工具栏 5 个按钮展示正确，未登录点击触发认证拦截
  4. 相关推荐侧栏展示 3-5 条帖子并可跳转
- **Verification**：`programmatic` + `human-judgment`（结构检查 + 视觉层级确认）

### AC-7：发帖编辑器流程
- **Given**：已登录用户访问 `/forum/editor`（未登录直接访问 → 跳登录页）
- **When**：填写标题、正文、选择版块与标签后点击发布
- **Then**：
  1. 前端创建 Mock 新帖对象（含自动生成 id 与 createdAt）
  2. 跳转到新帖详情页 `/forum/post/:newId`
  3. 标题或正文为空时阻止发布并展示占位提示
  4. AI 助手面板占位区静态展示（样式完整，无功能）
- **Verification**：`programmatic`（路由跳转 + 新帖创建）

### AC-8：个人主页展示与 Tab 切换
- **Given**：用户访问 `/forum/profile`
- **When**：查看资料卡并切换「发帖 / 收藏 / 关注 / 粉丝」Tab
- **Then**：
  1. 资料卡字段完整（头像、昵称、Handle、职业、城市、加入时间、简介、4 项计数、影响力评分）
  2. 关注按钮切换状态（未登录触发认证拦截）
  3. 4 个 Tab 对应列表展示 Mock 数据正确
- **Verification**：`programmatic`（Tab 切换内容变化）

### AC-9：登录注册页承接与跳转
- **Given**：用户从不同触发场景进入 `/forum/login`
- **When**：携带 `?from=editor` / `?from=timeout` / `?from=post_p1` 等参数
- **Then**：
  1. 页面顶部展示对应来源提示文案
  2. 登录成功后跳转回来源页面（无参数则回首页）
- **Verification**：`programmatic`（路由参数解析 + 跳转断言）

### AC-10：后台骨架页面
- **Given**：已登录用户访问 `/forum/admin/*`
- **When**：访问后台总览、用户管理、其他四个管理页
- **Then**：
  1. 后台总览 4 个核心指标卡数据正确渲染
  2. 用户管理页列表展示用户状态、角色筛选可用
  3. 其余 4 个后台页面骨架完整（标题 + 侧栏导航 + 占位内容）
- **Verification**：`human-judgment`（视觉骨架确认）

### AC-11：全局导航与响应式
- **Given**：用户在任意前台页面
- **When**：
  1. 使用顶部导航栏跳转各页面
  2. 调整浏览器窗口宽度到 <1024px、<768px、<600px
- **Then**：
  1. 所有导航链接无 404，返回正确页面
  2. 三档断点下布局不破版、内容不溢出、无横向滚动条
  3. 手机端导航栏优化展示（简化元素）
- **Verification**：`human-judgment`（人工交互 + 视觉检查）

### AC-12：构建验证
- **Given**：Phase0 全部代码完成
- **When**：执行 `npm run build`
- **Then**：构建成功、退出码为 0、dist/ 目录生成、无致命级错误（warning 允许但须评审）
- **Verification**：`programmatic`（命令退出码 + 产物存在）
